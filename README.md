# Task Manager

A simple web-based Task Manager application created as part of the Vistula University assignment.

**Student ID:** 72612

## Technologies

- HTML5
- CSS3
- JavaScript
- Supabase (PostgreSQL)
- Supabase REST API
- Git and GitHub
- GitHub Pages

## Live Application

[Open Task Manager](https://vistula-team-project-72612.github.io/vistula-task-manager/)

## Features

- Display all tasks
- Create new tasks
- Edit existing tasks
- Mark tasks as completed or incomplete
- Delete tasks
- Store tasks in Supabase database
- Persistent data storage
